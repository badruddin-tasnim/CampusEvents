3. Deep Technical Challenges & Resolution Log

Challenge 1: Cloud Firestore Network Coupling in Offline Test Suites

  • Problem Description: When executing automated unit tests, test suites attempted real HTTP connections to Firebase Firestore, failing when network latency spiked or during offline campus lab sessions.
  • Root Cause & Resolution: Learned and applied Vitest module mocking via vi.mock('firebase/firestore'). Intercepted raw SDK queries with in-memory deterministic responses and engineered a dual-mode persistence fallback in EventService utilizing local storage.
  • Engineering Lesson: Decoupling domain services from persistence implementations is imperative for reproducible testing.

Challenge 2: State Synchronization Across Decoupled Components

  • Problem Description: Upon reserving an event ticket in the details modal, the card seat quota on the home page and the navbar ticket count badge failed to reflect the updated count without manually refreshing the browser.
  • Root Cause & Resolution: Designed and implemented a centralized, lightweight publish-subscribe EventBus (Observer pattern). Wrapped subscriptions inside React's useEffect hook with dedicated unsubscriber cleanups, allowing components to reactively re-render upon RSVP_CONFIRMED broadcasts.
  • Engineering Lesson: Behavioral patterns provide clean, scalable event pipelines that preserve component decoupling.

Challenge 3: TDD Edge-Case Failure in Factory Validation

  • Problem Description: During TDD execution of EventFactory.test.js, the test verifying minimum sports team sizes failed unexpectedly when passed teamSize: 0.
  • Root Cause & Resolution: The constructor used JavaScript's short-circuit fallback: this.teamSize = Number(data.teamSize) || 1. Because 0 is falsy in JavaScript, the expression coerced valid zero-input to 1, causing validation to pass mistakenly. Corrected the expression to explicit existence checking: data.teamSize !== undefined ? Number(data.teamSize) : 1.
  • Engineering Lesson: Writing assertions prior to implementation exposes subtle language-level type coercion traps before code enters production.
